#### **Chapter 1 - Foundations - 1.1 Terminology - Sender and Receiver, Messages and Encryption, Algorithms and Keys, Symmetric Algorithms, Public-Key Algorithms**

- Sender & receiver - text needs to be transferred without anyone eavesdropping and reading the private text
- Privacy can be achieved through encryption: disguising a message to hide it's content is encryption, removing the disguise is decryption. Image below from source:
  
  <img width="582" height="155" alt="image" src="https://github.com/user-attachments/assets/973aa3f8-40eb-492e-a11c-818c7b175bb4" />

- Cryptography is the art and science of keeping messages secure
- Cryptanalysis on the other hand is the art of breaking this security
- Both of these are based ultimately on theoretical mathematics

- In addition to confidentiality, Cryptography provides:
  - **Authentication** - Making sure the receiver is the right person, attacker shouldn't be able to impersonate
  - **Integrity** - Verifying the content of the message is not modified 
  - **Nonrepudiation** - Sender should not be able to falsely deny sending the message

- Encryption is done using cryptographic algorithms (ciphers)
- Restricted algorithms require the type of algorithm to be kept secret and were used in the past
- Modern cryptography solves this problem with keys, such as with Public Key cryptography:

- Symmetric key encryption (1.2) is based on a single key (i.e. password) shared between users, any user with this key can encrypt and decrypt, so losing this key compromises the encryption


#### **Chapter 2 - Protocol Building Blocks, sections - 2.5 Communications Using Public-Key Cryptography**

- _A protocol is a series of steps, involving two or more parties, designed to accomplish a task_

- Public key encryption allows the public key to be distributed to a wide pool of users, who can use the public key to encrypt data and send it to the receiver. Only the receiver has the the private key to decrypt the received encrypted data.

Example from the book:
>- (1) Alice and Bob agree on a public-key cryptosystem.
>- (2) Bob sends Alice his public key.
>- (3) Alice encrypts her message using Bob's public key and sends it to Bob.
>- (4) Bob decrypts Alice's message using his private key.
